# v1.0.0 — Ruínas do Binômio

- Campanha com seis guardiões, chefe de três etapas e nove perguntas para o ensino médio.
- Introdução em pixel art, apresentação do chefe e encerramento com o herói escolhido.
- Três personagens, espada e arco, monstros animados e cenário DungeonTale.
- Música em loop, trilha própria do chefe, efeitos e controle de volume.
- Interface pixel art, câmera limitada e controles por toque com joystick e crítico.
- Exportação Windows x86_64. Adaptação móvel validada por simulação; Web e GitHub Pages ainda não publicados.
